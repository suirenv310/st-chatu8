Basic settings

4K model limits, including GPT Image 2: longest edge ≤3840; dimensions must be multiples of 16; maximum about 8.3MP (square: 2880x2880).
Native generation and separate Edits API guide
  • Separate endpoints：
    • Text-to-image: Call /v1/images/generations Endpoint; send only standard JSON parameters, without a nonstandard image field;
    • Img2img / image editing: When character references, preset images, or editing mode are active, use the separate /v1/images/edits Endpoint; upload image files with multipart/form-data by default.
  • Nonstandard community endpoint compatibility: If the site uses a singular endpoint (such as /v1/image/generation and /v1/image/edit), specified separately in the custom fields above.
  • Text-to-image model: If the site model supports only text-to-image, set Processing strategy to Text-to-image only.
  • Troubleshoot response format errors: If the site returns invalid_parameter_value (param: response_format), the model does not accept this field. Set Response format to Omit parameter to generate normally.

Prompt replacement rules

Banana/Grok-specific replacement rules, independent of other image backends. Format:trigger=mode|replacement

Replacement mode guide
  • Before prefix - Insert at the beginning of the prompt
  • After prefix - Insert after the fixed prefix
  • Replace - Replace the trigger directly (leave blank to remove)
  • Per-character replacement - Replace in per-character mode
  • Before suffix - Insert before the fixed suffix
  • After suffix - Insert after the fixed suffix
  • At the very end - Insert at the end of the prompt
